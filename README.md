## 同样写着10G，为什么价格差十倍

同样叫 10G，$94 和 $1199 之间隔着四个变量。每一个都能靠下单前问客服一句话确认，却能省掉日后的大麻烦。

### 端口独享还是共享

这是低价 10G 最常见的“水分”所在。有的商家会明确承诺 10G 端口零超额订阅，从你的服务器到机房上联全程独占；低价方案里的"10G"则可能是多台机器共享一条万兆上联，晚高峰跑不满属于正常现象。问法很直接：“端口是否独享、是否存在超额订阅”，答得含糊的就要留个心眼。

### 大陆优化和普通 BGP 差多少钱

线路是价差最夸张的一项。以 RAKsmart 同一台配置（E5-2620×2 / 128G / 4×1T SSD）为例：普通 BGP 线路 10G 月付 $399，大陆优化线路 $969，大陆优化 VIP 要 $1,169。同样的硬件，仅仅因为路由不同，价格差出 2.4 倍。

判断标准倒不复杂：业务或访客主要在中国大陆，大陆优化的钱省不得，BGP 再便宜也解决不了绕路问题；用户在全球分布，普通 BGP 就够，多付的钱买的是你用不上的路由优化。RAKsmart 的 10G 方案覆盖美国、香港、日本、韩国、马来西亚、德国多个机房，物理服务器和裸机云两条产品线都有，选择余地比较大。

### 不限流量和计量带宽怎么算

“不限流量”（Unmetered）方案普遍附带合理使用政策，Server Room 的条款里就写明了其不限流量 10G 方案遵循合理使用政策——持续满速跑一整个月，是有可能被限制的。计量方案则把流量明码标价：iWebFusion 的 10G 带宽配 150TB 月流量，只要 $149/月。

算笔账差距就出来了。假设月流量稳定在 150TB 以内，选计量方案一年比 $599 档的不限流量方案省下约 $5,400。真正需要不限流量的，是每月稳定跑两三百 TB 以上的分发类业务；流量没到那个量级，为“不限”两个字付溢价不太值。
